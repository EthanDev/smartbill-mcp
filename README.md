# smartbill-mcp

SmartBill.ro invoice automation: a private GitHub repo containing the Cloudflare Workers MCP server (smartbill) that Hermes agents connect to.

## Quickstart

Execute the plan at `.omo/plans/smartbill-invoice-automation.md` on the target Hermes instance (Mac Mini). It is self-contained: exact commands, endpoints, env vars, acceptance criteria, and QA scenarios. The SmartBill token is owner-supplied at runtime (ask the user when you reach the .dev.vars step).
